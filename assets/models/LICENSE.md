# Figurenmodelle

Alle Figuren in `quaternius/` stammen aus dem Paket **„Ultimate Animated Characters“ von Quaternius**
(https://quaternius.com), Lizenz **CC0 1.0** (Public Domain, frei für private und kommerzielle Nutzung,
keine Namensnennung nötig). Bezogen über das CC0-Spiegel-CDN cdn.cinevva.com, jeweils als einzelne GLB
mit eingebetteten Animationen (Idle, Walk, Run, SitDown, StandUp, PickUp, Victory, Defeat, Death, Punch, …).

| Datei | Verwendung |
|---|---|
| Soldier_Male / Soldier_Female | Soldaten aller Seiten |
| Casual_*, Casual2_*, Casual3_*, OldClassy_* | Zivilbevölkerung, Publikum |
| Worker_Male / Worker_Female | Rüstungsarbeiter |
| Suit_Male / Suit_Female | Delegationen, Redner, Offizielle |
| Kimono_Male / Kimono_Female | japanische Zivilisten |

Weitere CC0-Figuren aus demselben Paket (z. B. Chef, Cowboy, Ninja, Zombie, Survivalist) lassen sich
mit gleicher Benennung von `https://cdn.cinevva.com/assets/packs/quaternius/ultimate-animated-characters/<Name>.glb`
laden und in `js/common.js` unter `MODEL_FILES` eintragen.
